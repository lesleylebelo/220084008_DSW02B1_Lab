Student Profile Card
Description
The application displays a student's profile information, profile picture, and allows users to like the profile.

Features
React functional components
useState() for state management
useEffect() for side effects
Props for passing data between components
Profile picture display
Like Profile button
Live like counter
Modern responsive CSS styling
Card hover effects
Technologies Used
React
Vite
JavaScript
CSS
